# 🍵 নাস্তা অর্ডার

অফিসের নাস্তার অর্ডার, বাজারের লিস্ট আর টাকার হিসাব — একটাই জায়গায়।
মোবাইলে অ্যাপের মতো চলে (PWA), আলাদা করে ইনস্টল লাগে না।

**স্ট্যাক:** ASP.NET Core 8 (minimal API) + MSSQL + Dapper · ফ্রন্টএন্ড pure HTML/CSS/JS (কোনো বিল্ড স্টেপ নেই)

PIN অ্যাডমিন সেটিংস থেকে বদলাতে পারেন।

## যেভাবে কাজ করে

1. **স্টাফ সকালে জানায়** — 🟢 "অর্ডার নেওয়া হচ্ছে"। এটা সবার স্ক্রিনের উপরে ব্যানার হয়ে ভেসে ওঠে।
2. **সবাই অর্ডার দেয়** — আইটেম বেছে সংখ্যা দেয়। ডিমের মতো আইটেমে **ভাজি / পোচ / সিদ্ধ / ওমলেট** আলাদা করে বেছে নেওয়া যায় (দাম আলাদা হলে সেটাও যোগ হয়)।
3. **"না পেলে কী?"** — প্রতিটা আইটেমের নিচে ⚙ বোতাম: *নেব না* / *যেকোনো কিছু দিন* / *অন্য আইটেম দিন* (যেমন ডাল না থাকলে ভাজি) + বাড়তি নোট।
4. **বাজারে যাওয়ার আগে** স্টাফ **🛒 বাজারের লিস্ট** খোলে — আইটেম × সংখ্যা, কে কয়টা নিয়েছে, আর কার কী বিকল্প — সব এক পাতায়। চাইলে প্রিন্টও করা যায়।
5. স্টাফ অবস্থা বদলায় — 🛵 বাজারে যাওয়া হয়েছে → 📦 নাস্তা চলে এসেছে → ✅ পরিবেশন করা হয়েছে। অবস্থা বদলালেই সবার অ্যাপে দেখায় (২০ সেকেন্ডে চেক করে)।
6. **টাকার হিসাব (ঐচ্ছিক)** — কেউ ৫০০ টাকা জমা দিলে, প্রতিদিনের খরচ কেটে ব্যালেন্স দেখায়। ফেরত দিলে "ফেরত দেওয়া হয়েছে ✔" লেখা থাকে। পুরো মডিউলটা সেটিংস থেকে বন্ধ করা যায়।

> অর্ডার লক হওয়ার নিয়ম: স্টাফ কোনো অবস্থা দিলে সেটাই চলে (🟢 ছাড়া অন্য কিছু = আর বদলানো যাবে না)। স্টাফ কিছু না দিলে সেটিংসের **শেষ সময়** (ডিফল্ট ০৯:৩০) মানা হয়। স্টাফ/অ্যাডমিন যেকোনো সময় বদলাতে পারে।

## লোকালে চালানো

```bash
# ১) কানেকশন স্ট্রিং দিন (এই ফাইল gitignore করা আছে)
#    appsettings.Development.json
{
  "ConnectionStrings": {
    "Default": "Server=...;Database=...;User Id=...;Password=...;TrustServerCertificate=True;"
  }
}

# ২) চালান
dotnet run
```

খুললে → <http://localhost:5000>

প্রথমবার নিজে থেকেই টেবিল বানায়, ডেমো মেনু বসায় আর একজন অ্যাডমিন তৈরি করে:

```
নাম: admin      পাসওয়ার্ড: 123456
```

**প্রথম কাজ:** লগইন করে *আরও → পাসওয়ার্ড বদলান*, তারপর *সেটিংস* থেকে অফিসের নাম আর রেজিস্ট্রেশন PIN বদলে নিন।

আইকন বদলাতে চাইলে: `node tools/gen-icons.js` (Node লাগবে, শুধু আইকনের জন্য)।

## MonsterASP-এ লাইভ করা

### ১. অ্যাকাউন্ট ও সাইট
1. মেইলের **Activation Code** দিয়ে অ্যাকাউন্ট চালু করুন → <https://admin.monsterasp.net>
2. **Websites → Create** → সাইট বানান। নাম হবে `siteXXXXX`, ঠিকানা `siteXXXXX.runasp.net`
3. সাইটের **.NET version = .NET 8**, **Pipeline = Integrated** রাখুন

### ২. ডেটাবেজ
1. **Databases → MSSQL → Create**
2. তৈরি হওয়া **Connection String** কপি করুন। শেষে `TrustServerCertificate=True;` না থাকলে যোগ করে নিন।

### ৩. GitHub Secrets
রিপোর ⚙ **Settings → Secrets and variables → Actions → New repository secret**:

| Secret | কী দেবেন |
|---|---|
| `MONSTERASP_FTP_HOST` | `siteXXXXX.siteasp.net` |
| `MONSTERASP_FTP_USER` | `siteXXXXX` |
| `MONSTERASP_FTP_PASSWORD` | প্যানেলের FTP পাসওয়ার্ড |
| `NASTA_DB` | MSSQL কানেকশন স্ট্রিং |

`NASTA_DB` না দিলেও চলবে — তখন সার্ভারে নিজে হাতে একবার `wwwroot/appsettings.Production.json` রেখে দিন, ডিপ্লয় সেটা মুছবে না।

### ৪. ডিপ্লয়
`main`-এ push করলেই **অটো লাইভ** হবে ([.github/workflows/deploy-monsterasp.yml](.github/workflows/deploy-monsterasp.yml))।

কাজের ধাপ: publish → `app_offline.htm` তুলে IIS থামানো (নইলে `NastaOrder.dll` লক থাকে) → FTP আপলোড → `app_offline.htm` মুছে অ্যাপ চালু → warm-up ping।

### ৫. SSL সার্টিফিকেট
1. প্যানেলে **Websites → (আপনার সাইট) → SSL/TLS**
2. **Let's Encrypt (Free)** বেছে **Request / Install** চাপুন — `siteXXXXX.runasp.net`-এর জন্য ফ্রি
3. হয়ে গেলে **Force HTTPS** চালু করুন (`web.config`-এ HTTPS রিডাইরেক্ট রুলও দেওয়া আছে)
4. নিজের ডোমেইন লাগালে আগে **Domains** থেকে ডোমেইন যোগ করে DNS পয়েন্ট করুন, তারপর ওই ডোমেইনের জন্য আবার Let's Encrypt চাপুন

> HTTPS ছাড়া PWA "হোম স্ক্রিনে যোগ করুন" ঠিকমতো কাজ করে না — তাই SSL বসানো জরুরি।

## সিক্রেট নিয়ে নিয়ম

আসল পাসওয়ার্ড বা কানেকশন স্ট্রিং **কখনো কোডে বা রিপোতে যায় না**।
`appsettings.Development.json`, `appsettings.Production.json`, `*.PublishSettings` — সব `.gitignore`-এ আছে।
লাইভে সেগুলো আসে GitHub Secrets বা সার্ভারের নিজের ফাইল থেকে।
